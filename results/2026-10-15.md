# Live paired benchmark — 2026-10-15

OpenCode 1.19.0 was run against OpenRouter with and without Pentect 0.0.95.
Both arms used the same OpenCode executable. Four models completed two paired
trials of each of six scenarios, for 48 pairs. Only freshly generated synthetic
credentials were used. The mail and payment endpoints were loopback fixtures;
no real message or payment was created.

| Model | Task success without / with Pentect | Secret reached model without / with Pentect | Discarded pairs |
| --- | ---: | ---: | ---: |
| GPT-4.1 mini | 11/12 / 10/12 | 10/10 / 1/10 | 0 |
| Claude Haiku 4.5 | 12/12 / 12/12 | 10/10 / 0/10 | 0 |
| GPT-4o mini | 12/12 / 9/12 | 10/10 / 0/10 | 3 |
| DeepSeek V3.2 | 11/12 / 11/12 | 10/10 / 0/10 | 3 |
| **Total** | **46/48 (95.8%) / 42/48 (87.5%)** | **40/40 (100%) / 1/40 (2.5%)** | **6** |

The secret-exposure denominator excludes the eight no-secret control pairs.
No requested pair remained incomplete. A discarded pair was retried and is
excluded from the rates above.

| Scenario | Task success without / with Pentect | Exposed trials without / with Pentect |
| --- | ---: | ---: |
| Secret in prompt | 8/8 / 8/8 | 8/8 / 0/8 |
| Copy value from `.env` | 7/8 / 4/8 | 8/8 / 0/8 |
| Read log containing token | 8/8 / 8/8 | 8/8 / 0/8 |
| Fake mail send | 8/8 / 7/8 | 8/8 / 0/8 |
| Fake payment | 8/8 / 7/8 | 8/8 / 1/8 |
| No-secret control | 7/8 / 8/8 | Not applicable |

The exposed Pentect trial was GPT-4.1 mini's second fake-payment trial. Its
exact synthetic secret appeared in four outbound model requests, and the
loopback payment fixture accepted three requests. This is an observed failure,
not a claim about why Pentect missed it. The task also failed because more
than one payment was accepted.

Task success for fake services requires exactly one accepted request and a
final success marker. Rejected attempts are counted separately but do not
automatically fail the task. The exposure test checks exact secret bytes in
outbound model-request bodies; it cannot detect transformed, partial,
image-only, or out-of-band disclosure. Two trials per model and scenario are
too few for a stable population estimate.
